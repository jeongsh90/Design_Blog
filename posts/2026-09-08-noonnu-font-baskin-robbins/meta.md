# 제목: 배스킨라빈스체 무료 한글 웹폰트 — 아이스크림 매장 간판 그 서체

- 카테고리: Design > Font
- 태그: 배스킨라빈스체, 무료폰트, 한글폰트, 장식체, 웹폰트
- 메타디스크립션: 비알코리아가 헤움디자인과 함께 만든 무료 한글 브랜드 폰트 배스킨라빈스체를 실제 페이지 기준으로 검증해 라이선스와 웹폰트 코드까지 정리했습니다.
- 썸네일: attachments/thumbnail.png(1200×630, IHDR 픽셀 크기 검증 완료)

## 제외된 항목
- 없음

## 발행 안내
1. 티스토리 글쓰기 → HTML 모드 전환 → final.html 내용 붙여넣기
2. 카테고리 Design > Font 지정, 위 태그 입력
3. 대표이미지로 attachments/thumbnail.png 첨부
4. **신규 발행 직후 CDN 16:9 패딩 버그 예방 절차 필수**: 대표이미지를 한 번 삭제 후 같은 파일을 재업로드→재발행(R1200x0으로 실제 노출 크기 재검증)
5. 당일 공개 발행 한도(15개)를 확인한 뒤 공개로 저장

## 검증 기록
- 1차 출처: noonnu.cc 배스킨라빈스체 페이지(font_page/246)
- 확인 시점: 2026-09-08
- 직접 검증한 항목: Playwright로 페이지의 style 태그와 본문 텍스트를 직접 evaluate해 @font-face(woff, 2가지 굵기), 라이선스 본문·요약표, 실제 다운로드 링크(a 태그 href) 실측 확인.
- 이 페이지에는 "웹폰트로 사용" 별도 복사 섹션이 없어(다른 다수 폰트와 차이), 페이지에 실제 선언된 @font-face(BRRA_R/BRBA_B) 원본 그대로 사용.
- 미검증 항목: Google 드라이브 폴더 실제 다운로드까지는 수행하지 않음(링크 URL만 확인).

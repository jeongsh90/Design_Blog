# 제목: 여기어때 잘난체 무료 한글 웹폰트 — 둥글면서도 꽉 찬 장식 고딕체

- 카테고리: Design > Font
- 태그: 여기어때잘난체, 무료폰트, 한글폰트, 장식체, 웹폰트
- 메타디스크립션: 여기어때컴퍼니가 배포하는 무료 한글 폰트 여기어때 잘난체를 실제 페이지 기준으로 검증해 라이선스(임베딩·BI/CI 조건부 허용)와 웹폰트 코드까지 정리했습니다.
- 썸네일: attachments/thumbnail.png(1200×630, IHDR 픽셀 크기 검증 완료)

## 제외된 항목
- 없음

## 발행 안내
1. 티스토리 글쓰기 → HTML 모드 전환 → final.html 내용 붙여넣기
2. 카테고리 Design > Font 지정, 위 태그 입력
3. 대표이미지로 attachments/thumbnail.png 첨부
4. **신규 발행 직후 CDN 16:9 패딩 버그 예방 절차 필수**: 대표이미지를 한 번 삭제 후 같은 파일을 재업로드→재발행(R1200x0으로 실제 노출 크기 재검증)
5. 당일 공개 발행 한도(15개)를 확인한 뒤 공개로 저장

## 검증 기록
- 1차 출처: noonnu.cc 여기어때 잘난체 페이지(font_page/115)
- 확인 시점: 2026-09-08
- 직접 검증한 항목: @font-face 코드는 Playwright로 noonnu 페이지를 직접 열어 `document.documentElement.innerHTML`에서 정규식으로 실측 확인(WebFetch 미사용) — 하단 "웹폰트로 사용" 섹션의 `font-family: 'YeogiOttaeJalnan'` 값 채택(상단 미리보기 인라인 스타일은 'yg-jalnan'으로 다름). 라이선스 본문·요약표 전문 대조.
- **주의**: 요약표에서 임베딩과 BI/CI를 "조건부 허용"으로 명시한 드문 사례다. 본문은 폰트 파일 자체의 임의 수정·재배포는 금지하지만, 인쇄물·광고물·CI/BI에 실제 적용할 때는 형태 수정·변환까지 허용한다고 구체적으로 구분해 안내한다 — 정확한 사용 범위는 원본 라이선스 전문에서 재확인 권장.
- 미검증 항목: goodchoice.kr 다운로드 페이지 및 원본 라이선스 전문 링크의 실제 열람까지는 수행하지 않음(눈누 페이지의 인용문만 확인)

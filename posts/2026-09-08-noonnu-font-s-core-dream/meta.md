# 제목: 에스코어드림 무료 한글 웹폰트 — Thin부터 Black까지, 9단계 촘촘한 고딕

- 카테고리: Design > Font
- 태그: 에스코어드림, 무료폰트, 한글폰트, 고딕체, 웹폰트
- 메타디스크립션: S-Core가 배포하는 무료 한글 폰트 에스코어드림을 실제 페이지 기준으로 검증해 라이선스와 9가지 굵기 전체 웹폰트 코드까지 정리했습니다.
- 썸네일: attachments/thumbnail.png(1200×630, IHDR 픽셀 크기 검증 완료)

## 제외된 항목
- 없음

## 발행 안내
1. 티스토리 글쓰기 → HTML 모드 전환 → final.html 내용 붙여넣기
2. 카테고리 Design > Font 지정, 위 태그 입력
3. 대표이미지로 attachments/thumbnail.png 첨부
4. **신규 발행 직후 CDN 16:9 패딩 버그 예방 절차 필수**: 대표이미지를 한 번 삭제 후 같은 파일을 재업로드→재발행(R1200x0으로 실제 노출 크기 재검증)
5. 당일 공개 발행 한도(15개)를 확인한 뒤 공개로 저장

## 검증 기록
- 1차 출처: noonnu.cc 에스코어드림 페이지(font_page/223)
- 확인 시점: 2026-09-08
- 직접 검증한 항목: @font-face 코드는 Playwright browser_evaluate로 noonnu 페이지를 fetch+DOMParser로 직접 파싱해 실측 확인(WebFetch 미사용, id=fontCopy223 엘리먼트 원문 그대로). 라이선스 본문·요약표 전문 대조.
- 9개 @font-face 블록(100~900) 전체를 실측해 굵기·파일명이 하나도 누락 없이 이어짐을 확인.
- 미검증 항목: S-Core 공식 다운로드 페이지의 실제 다운로드 절차는 수행하지 않음(링크 URL만 확인).

# 제목: 도스명조 무료 한글 웹폰트 — 옛 도스 화면을 닮은 픽셀 명조체

- 카테고리: Design > Font
- 태그: 도스명조, 무료폰트, 한글폰트, 명조체, 웹폰트
- 메타디스크립션: 개인 제작자 leedheo가 MIT 라이선스로 배포하는 무료 한글 폰트 도스명조를 실제 페이지 기준으로 검증해 라이선스와 웹폰트 코드까지 정리했습니다.
- 썸네일: attachments/thumbnail.png(1200×630, IHDR 픽셀 크기 검증 완료)

## 제외된 항목
- 없음

## 발행 안내
1. 티스토리 글쓰기 → HTML 모드 전환 → final.html 내용 붙여넣기
2. 카테고리 Design > Font 지정, 위 태그 입력
3. 대표이미지로 attachments/thumbnail.png 첨부
4. **신규 발행 직후 CDN 16:9 패딩 버그 예방 절차 필수**: 대표이미지를 한 번 삭제 후 같은 파일을 재업로드→재발행(R1200x0으로 실제 노출 크기 재검증)
5. 당일 공개 발행 한도(15개)를 확인한 뒤 공개로 저장

## 검증 기록
- 1차 출처: noonnu.cc 도스명조 페이지(font_page/238)
- 확인 시점: 2026-09-08
- 직접 검증한 항목: @font-face 코드는 Playwright browser_evaluate로 noonnu 페이지를 fetch+DOMParser로 직접 파싱해 실측 확인(WebFetch 미사용, id=fontCopy238 엘리먼트 원문 그대로). 라이선스 본문·요약표 전문 대조.
- 라이선스 본문이 GitHub 저장소 기반 MIT 라이선스임을 명시하고 있음을 확인 — 요약표는 다른 폰트들과 동일한 형식으로 별도 표기.
- 미검증 항목: GitHub 저장소의 실제 파일 다운로드까지는 수행하지 않음(링크 URL만 확인).

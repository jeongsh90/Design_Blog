# 제목: 헬스셋 조릿대체 무료 한글 웹폰트 — 붓끝이 갈라진 듯한 대나무 질감의 고전체

- 카테고리: Design > Font
- 태그: 헬스셋조릿대체, 무료폰트, 한글폰트, 고전체, 웹폰트
- 메타디스크립션: 헬스셋이 배포하는 무료 한글 폰트 헬스셋 조릿대체를 실제 페이지 기준으로 검증해 라이선스와 웹폰트 코드까지 정리했습니다.
- 썸네일: attachments/thumbnail.png(1200×630, IHDR 픽셀 크기 검증 완료)

## 제외된 항목
- 없음

## 발행 안내
1. 티스토리 글쓰기 → HTML 모드 전환 → final.html 내용 붙여넣기
2. 카테고리 Design > Font 지정, 위 태그 입력
3. 대표이미지로 attachments/thumbnail.png 첨부
4. **신규 발행 직후 CDN 16:9 패딩 버그 예방 절차 필수**: 대표이미지를 한 번 삭제 후 같은 파일을 재업로드→재발행(R1200x0으로 실제 노출 크기 재검증)
5. 당일 공개 발행 한도(15개)를 확인한 뒤 공개로 저장

## 검증 기록
- 1차 출처: noonnu.cc 헬스셋 조릿대체 페이지(font_page/124)
- 확인 시점: 2026-09-08
- 직접 검증한 항목: @font-face 코드는 Playwright browser_evaluate로 noonnu 페이지를 fetch+DOMParser로 직접 파싱해 실측 확인(WebFetch 미사용, id=fontCopy124 엘리먼트 원문 그대로). 라이선스 본문·요약표 전문 대조.
- 다운로드가 헬스셋 홈페이지 회원가입 후에만 가능하다는 이례적 조건을 라이선스 본문에서 확인.
- 미검증 항목: 헬스셋 홈페이지 회원가입 및 실제 다운로드 절차는 수행하지 않음(링크 URL만 확인).

# 제목: 가비아 봄바람체 무료 한글 웹폰트 — 바람에 흩날리는 장식 손글씨체

- 카테고리: Design > Font
- 태그: 가비아봄바람체, 무료폰트, 한글폰트, 장식체, 웹폰트
- 메타디스크립션: 가비아가 배포하는 무료 한글 폰트 가비아 봄바람체를 실제 페이지 기준으로 검증해 라이선스와 웹폰트 코드까지 정리했습니다.
- 썸네일: attachments/thumbnail.png(1200×630, IHDR 픽셀 크기 검증 완료)

## 제외된 항목
- 없음

## 발행 안내
1. 티스토리 글쓰기 → HTML 모드 전환 → final.html 내용 붙여넣기
2. 카테고리 Design > Font 지정, 위 태그 입력
3. 대표이미지로 attachments/thumbnail.png 첨부
4. **신규 발행 직후 CDN 16:9 패딩 버그 예방 절차 필수**: 대표이미지를 한 번 삭제 후 같은 파일을 재업로드→재발행(R1200x0으로 실제 노출 크기 재검증)
5. 당일 공개 발행 한도(15개)를 확인한 뒤 공개로 저장

## 검증 기록
- 1차 출처: noonnu.cc 가비아 봄바람체 페이지(font_page/70)
- 확인 시점: 2026-09-08
- 직접 검증한 항목: @font-face 코드는 Playwright로 noonnu 페이지를 직접 열어 `document.documentElement.innerHTML`에서 정규식으로 실측 확인(WebFetch 미사용) — 3개 노출 코드 모두 `font-family: 'GabiaBombaram'`으로 동일. 라이선스 본문·다운로드 링크가 자매 폰트 가비아 솔미체(font_page/69)와 동일함을 재확인. HS봄바람체 2.0(배치7, 별도 제작사)과는 이름만 비슷할 뿐 완전히 다른 폰트임을 확인.
- 미검증 항목: company.gabia.com 폰트 페이지의 실제 다운로드 절차까지는 수행하지 않음(링크 URL만 확인)

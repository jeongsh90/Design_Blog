라이선스

Move Sans(무브 산스) 폰트는 아래와 같이 구성되어 있다. - MoveSans-Light.ttf - MoveSans-Medium.ttf - MoveSans-Bold.ttf - MoveSans-Light.otf - MoveSans-Medium.otf - MoveSans-Bold.otf - 야핏무브에서 무료로 배포하는 Move Sans(무브 산스) 폰트의 지적 재산권은 (주)야나두에 있다. - Move Sans(무브 산스) 폰트는 개인 및 기업 사용자를 포함한 모든 사용자가 무료로 사용할 수 있다. - 단, 폰트 원본 파일 임의 수정, 변경, 변형, 복제 및 유상 판매를 할 수 없습니다. - 아래 사용 가능/불가능 범위를 참고하여 사용한다. - 사용 가능 범위 - 온/오프라인 광고, 인쇄, 웹, 모바일, 영상, 포장지, 제품, 임베딩, 영리적/비영리적 목적 사용 - 사용 불가능 범위 - BI/CI, OFL, 유상 판매 - 다른 소프트웨어와 번들, 재배포하는 경우 출처 표기를 필수로 한다. - 예) 해당 페이지에는 야핏무브의 'Move Sans Medium’ 폰트가 적용되어 있다. - Move Sans(무브 산스) 폰트를 사용한 제작물 이미지는 야나두, 야핏, 야핏무브 브랜드 홍보 목적으로 활용될 수 있다. 웹폰트 코드

웹폰트로 사용할 때 필요한 코드는 다음과 같다. 3가지 굵기를 제공한다.

@font-face {
    font-family: 'MoveSans-Bold';
    src: url('https://cdn.jsdelivr.net/gh/projectnoonnu/2405-2@1.0/MoveSans-Bold.woff2') format('woff');
    font-weight: 700;
    font-display: swap;
}

@font-face {
    font-family: 'MoveSans-Light';
    src: url('https://cdn.jsdelivr.net/gh/projectnoonnu/2405-2@1.0/MoveSans-Light.woff2') format('woff');
    font-weight: 300;
    font-display: swap;
}

@font-face {
    font-family: 'MoveSans-Medium';
    src: url('https://cdn.jsdelivr.net/gh/projectnoonnu/2405-2@1.0/MoveSans-Medium.woff2') format('woff');
    font-weight: 500;
    font-display: swap;
}

- 태그: 빙그레메로나체, 무료폰트, 한글폰트, 장식체, 웹폰트
- 메타디스크립션: 빙그레가 메로나 브랜드를 모티브로 배포하는 무료 한글 폰트 빙그레 메로나체(레귤러·볼드 2가지 굵기)를 실제 페이지 기준으로 검증했습니다.

## 발행 안내
1. 티스토리 글쓰기 → HTML 모드 전환 → final.html 내용 붙여넣기
2. 카테고리 Design > Font 지정, 위 태그 입력
3. 대표이미지로 attachments/thumbnail.png 첨부
4. **신규 발행 직후 CDN 16:9 패딩 버그 예방 절차 필수**: 대표이미지를 한 번 삭제 후 같은 파일을 재업로드→재발행(R1200x0으로 실제 노출 크기 재검증)
5. 당일 공개 발행 한도(15개)를 확인한 뒤 공개로 저장

## 검증 기록
- 1차 출처: noonnu.cc 빙그레 메로나체 페이지(font_page/320)
- 확인 시점: 2026-09-08
- 직접 검증한 항목: Playwright로 페이지의 style 태그와 본문 텍스트를 직접 evaluate해 @font-face(woff, 2가지 굵기), 라이선스 본문·요약표(BI/CI 사용 불가 조항 포함), 실제 다운로드 링크(a 태그 href, bing.co.kr) 실측 확인.
- 이례적 라이선스 조건: BI/CI(회사명·브랜드명·로고 등) 사용이 명시적으로 금지됨 — 다른 다수 폰트(사용 가능)와 차이가 있어 본문에 강조 표기.
- 미검증 항목: 빙그레 사이트의 실제 파일 다운로드까지는 수행하지 않음(링크 URL만 확인).

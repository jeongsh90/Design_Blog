# 제목: 다래손글씨체 무료 한글 웹폰트 — 삐뚤빼뚤한 마카 손글씨체

- 카테고리: Design > Font
- 태그: 다래손글씨체, 무료폰트, 한글폰트, 손글씨체, 웹폰트
- 메타디스크립션: 개인 제작자 김다래가 배포하는 무료 한글 폰트 다래손글씨체를 실제 페이지 기준으로 검증해 라이선스(대기업·공기업 사전 허락 필요 조항 포함)와 웹폰트 코드까지 정리했습니다.
- 썸네일: attachments/thumbnail.png(1200×630, IHDR 픽셀 크기 검증 완료)

## 제외된 항목
- 없음

## 발행 안내
1. 티스토리 글쓰기 → HTML 모드 전환 → final.html 내용 붙여넣기
2. 카테고리 Design > Font 지정, 위 태그 입력
3. 대표이미지로 attachments/thumbnail.png 첨부
4. **신규 발행 직후 CDN 16:9 패딩 버그 예방 절차 필수**: 대표이미지를 한 번 삭제 후 같은 파일을 재업로드→재발행(R1200x0으로 실제 노출 크기 재검증)
5. 당일 공개 발행 한도(15개)를 확인한 뒤 공개로 저장

## 검증 기록
- 1차 출처: noonnu.cc 다래손글씨체 페이지(font_page/90)
- 확인 시점: 2026-09-08
- 직접 검증한 항목: @font-face 코드는 Playwright로 noonnu 페이지를 직접 열어 `document.documentElement.innerHTML`에서 정규식으로 실측 확인(WebFetch 미사용) — 하단 "웹폰트로 사용" 섹션의 `font-family: 'DaraeHandwriting'` 값 채택(상단 미리보기 인라인 스타일은 'drfont_daraehand'로 다름). 라이선스 본문·요약표 전문 대조.
- **주의**: 300인 이상 규모의 대기업·공기업은 별도 사전 허락을 받은 뒤 사용해야 한다는 조항이 있다 — 다른 눈누 폰트에서는 드문 기업 규모 기준 제한이다. 라이선스 전문은 저작권자 블로그(blog.naver.com/drstyle/30158806258)에 별도 게시돼 있음(원문 페이지는 직접 열람하지 않음).
- 미검증 항목: 구글 드라이브 다운로드 링크의 실제 다운로드 절차, 저작권자 블로그의 라이선스 전문까지는 확인하지 않음(눈누 페이지의 요약과 일부 인용만 확인)

# 제목: 즐거운이야기체 무료 한글 웹폰트 — 붓끝의 흐름을 살린 경쾌한 캘리그라피

- 카테고리: Design > Font
- 태그: 즐거운이야기체, 무료폰트, 한글폰트, 캘리그라피, 웹폰트
- 메타디스크립션: CJ E&M(tvN)이 배포하는 무료 한글 폰트 즐거운이야기체를 실제 페이지 기준으로 검증해 라이선스(재배포 시 출처 표기 필수 조항 포함)와 웹폰트 코드까지 정리했습니다.
- 썸네일: attachments/thumbnail.png(1200×630, IHDR 픽셀 크기 검증 완료)

## 제외된 항목
- 없음

## 발행 안내
1. 티스토리 글쓰기 → HTML 모드 전환 → final.html 내용 붙여넣기
2. 카테고리 Design > Font 지정, 위 태그 입력
3. 대표이미지로 attachments/thumbnail.png 첨부
4. **신규 발행 직후 CDN 16:9 패딩 버그 예방 절차 필수**: 대표이미지를 한 번 삭제 후 같은 파일을 재업로드→재발행(R1200x0으로 실제 노출 크기 재검증)
5. 당일 공개 발행 한도(15개)를 확인한 뒤 공개로 저장

## 검증 기록
- 1차 출처: noonnu.cc 즐거운이야기체 페이지(font_page/82)
- 확인 시점: 2026-09-08
- 직접 검증한 항목: @font-face 코드는 Playwright로 noonnu 페이지를 직접 열어 `document.documentElement.innerHTML`에서 정규식으로 실측 확인(WebFetch 미사용) — 하단 "웹폰트로 사용" 섹션의 `font-family: 'JoyfulStory'` 값 채택(상단 미리보기 인라인 스타일은 'OTEnjoystoriesBA'로 다름). 라이선스 본문·요약표 전문 대조.
- **주의**: 다른 소프트웨어와 번들·응용해 재배포할 경우 출처 표기(예: "이 페이지에는 'tvN 즐거운이야기'가 적용되어 있습니다")가 필수라는 조항이 있다.
- 미검증 항목: CJ E&M(tvN) 공식 페이지의 실제 다운로드 절차까지는 수행하지 않음(링크 URL만 확인)

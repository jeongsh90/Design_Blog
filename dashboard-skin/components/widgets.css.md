## 16. [실측 보정 — 스펙 §2-2 CSS에 없던 1줄 추가]

   아이템이 되므로 어느 쪽이든 동작한다.

## 36. 8. 커스텀 스크롤바 → **components/scrollbar.css 로 이동했다

════════════════════════════════════════════════════════════════
   8. 커스텀 스크롤바 → **components/scrollbar.css 로 이동했다**
   ────────────────────────────────────────────────────────────────
   [2026-09-04, CONTENT SPEC §3-1 / §14-1] 원래 여기(구 370~444행)에
   있던 §8 블록 전체를 값 한 글자도 바꾸지 않고 `components/scrollbar.css`
   공용 프리미티브로 옮겼다. 셀렉터만 `[data-slot="widgets"]` →
   `[data-custom-scrollbar]`로 바뀌었고, `skin.html`의 `<aside
   data-slot="widgets">`에 `data-custom-scrollbar` 속성이 추가됐다.

   추출 사유: content 구역의 `[data-slot="content-inner"]`가 완전히
   동일한 스크롤바를 쓰게 되어 두 번째 사용처가 생겼다 — 이 프로젝트가
   이미 두 번 적용한 "다른 구역이 쓰기 시작하면 프리미티브로 추출한다"
   규칙(Button/Breadcrumb, Tooltip)에 정확히 해당한다.

   ⚠ 이 패널의 스크롤바 동작·색·타이밍은 이동 전과 완전히 동일해야 한다
     (회귀 0). 값이 아니라 셀렉터만 바뀐 리팩터링이다.

스포카 한 산스는 스포카가 만든 무료 한글 폰트다. Thin·Light·Regular·Bold 4가지 굵기를 갖춘 꽉 찬 고딕체로, 화면 UI나 서비스 본문처럼 가독성이 중요한 자리에 잘 어울린다.

군더더기 없이 실용적인 UI 고딕체입니다.

라이선스

스포카 한 산스는 SIL 오픈 폰트 라이선스(OFL) 1.1을 따른다. 개인·기업·단체 누구나 무료로 사용·복사·수정·재배포할 수 있으며, 원본이든 수정본이든 저작권 안내와 라이선스 내용을 포함하기만 하면 다른 소프트웨어와 묶어 배포하거나 판매하는 것도 가능하다. 다만 폰트명 자체를 저작권자 허가 없이 수정본에 그대로 쓸 수는 없다.

※ 위 표는 참고용으로 정리한 요약이다. 정확한 사용 범위는 저작권자(스포카)에게 확인하는 것이 안전하다.

웹폰트 코드

웹폰트로 사용할 때 필요한 코드는 다음과 같다(Regular 굵기 기준, Thin·Light·Bold는 각각 별도 @font-face로 추가하면 된다).

@font-face {
    font-family: 'Spoqa Han Sans';
    font-weight: 400;
    src: url('https://cdn.jsdelivr.net/gh/spoqa/spoqa-han-sans@01ff0283e4f36e159ffbf744b36e16ef742da6d8/Subset/SpoqaHanSans/SpoqaHanSansRegular.woff2') format('woff2'),
         url('https://cdn.jsdelivr.net/gh/spoqa/spoqa-han-sans@01ff0283e4f36e159ffbf744b36e16ef742da6d8/Subset/SpoqaHanSans/SpoqaHanSansRegular.woff') format('woff');
}

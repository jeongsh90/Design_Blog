본고딕(Noto Sans KR)은 Google과 Adobe가 함께 만든 무료 한글 폰트다. 전 세계 여러 언어를 아우르는 Noto 프로젝트의 한글판으로, 어떤 화면·매체에서도 무난하게 통하는 기본 고딕체다.

어디서나 통하는 국제 표준 고딕체입니다.

라이선스

본고딕은 SIL 오픈 폰트 라이선스(OFL) 1.1을 따른다. 개인·기업·단체 누구나 무료로 사용·복사·수정·재배포할 수 있으며, 원본이든 수정본이든 저작권 안내와 라이선스 내용을 포함하기만 하면 다른 소프트웨어와 묶어 배포하거나 판매하는 것도 가능하다. 다만 폰트명 자체를 저작권자 허가 없이 수정본에 그대로 쓸 수는 없다.

웹폰트 코드

웹폰트로 사용할 때 필요한 코드는 다음과 같다.

@font-face {
    font-family: 'Noto Sans KR';
    src: url('https://fonts.gstatic.com/s/notosanskr/v39/PbyxFmXiEBPT4ITbgNA5Cgms3VYcOA-vvnIzzuoyeLQ.ttf') format('truetype');
    font-weight: normal;
    font-display: swap;
}

경기천년바탕은 경기도청이 만들어 배포하는 무료 한글 폰트다. 붓의 흐름을 살린 바탕(명조) 계열이라 결이 차분하고, 레귤러와 볼드 두 가지 굵기를 갖추고 있어 본문과 강조 문구를 한 벌로 짝지어 쓰기 좋다.

천년의 결을 담은 단정한 바탕체입니다.

라이선스

경기도 서체는 누구나 무료로 다운로드해 영상·인쇄·웹 등 다양한 매체에 자유롭게 사용할 수 있고, 별도의 허가 절차도 필요 없다. 다만 서체를 유료로 양도하거나 판매하는 등의 상업적 행위는 금지된다.

웹폰트 코드

웹폰트로 사용할 때 필요한 코드는 다음과 같다. 레귤러와 볼드 두 굵기를 함께 선언해 두면 font-weight 값만으로 굵기를 바꿔 쓸 수 있다.

@font-face {
    font-family: 'GyeonggiMillenniumBackground';
    src: url('https://cdn.jsdelivr.net/gh/projectnoonnu/2410-3@1.0/Batang_Regular.woff') format('woff');
    font-weight: 400;
    font-display: swap;
}
@font-face {
    font-family: 'GyeonggiMillenniumBackground';
    src: url('https://cdn.jsdelivr.net/gh/projectnoonnu/2410-3@1.0/Batang_Bold.woff') format('woff');
    font-weight: 700;
    font-display: swap;
}

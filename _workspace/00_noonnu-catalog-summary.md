# 눈누(noonnu.cc) 폰트 카탈로그 목록 실측 수집 요약

## 실측 총 개수
- **1,170개** (중복 제거 후 고유 `font_page` id 기준)
- 원본 DOM에서 무한 스크롤로 전부 로드한 뒤 `a[href*="font_page/"]` 앵커 전체 개수: 1,172개
- 이 중 완전히 동일한 id가 2건(각 1개씩 초과) 발견돼 제거 → 1,170개 확정

## 수집 방법 (실측치)
- 대상 페이지: https://noonnu.cc/index
- 방식: `window.scrollTo(0, document.body.scrollHeight)` 후 대기를 반복하는 무한 스크롤 자동화(Playwright `browser_evaluate`, 비동기 루프로 페이지 안에서 직접 반복 처리)
- 스크롤 반복 횟수: 54회(각 스크롤 사이 900ms 대기) 만에 카드 개수가 4회 연속 변화 없음(`1172`에서 안정) 확인
- 안정화 재확인: 이후 추가로 6회(각 2초 대기) 더 스크롤을 시도했으나 개수 변화 없음(`1172` 그대로) — 로딩 완료로 판단
- 추출 방식: `page.evaluate()` 1회 호출로 전체 카드 DOM을 순회하며 폰트명(`img[alt]`)·상세페이지 id(`href`의 `/font_page/{id}`)·디자이너/제작사(`p.font-bold` 텍스트)·굵기 종류(`[data-fonts-target="fontVariantsCount"]` 텍스트)를 한 번에 수집

## 이상 징후
1. **중복 2건**: id `253`, `1144`이 무한 스크롤 배치 경계에서 각각 한 번씩 더 나타남(스크롤 로딩 시 배치가 겹쳐 삽입된 것으로 추정). 최종 JSON에는 첫 등장분만 남기고 중복 제거함.
2. **굵기 정보 없음(null) 919건**: 전체 1,170개 중 919개(약 78%)는 카드에 "N가지 굵기" 표시 자체가 없음(해당 위치가 빈 `<div></div>`). DOM을 직접 확인한 결과 이는 추출 실패가 아니라 **사이트 자체가 단일 굵기 폰트에는 "N가지 굵기" 라벨을 표시하지 않는 실제 동작**임을 확인함(예: id 1663 "메모먼트 꾹꾹체"는 `@font-face`에 단일 `font-weight: normal` 웹폰트 하나만 정의돼 있고 카드에도 굵기 라벨이 없음). 즉 `weights: null`은 "단일 굵기(또는 미표시)" 상태를 그대로 반영한 값이며 별도 조치 없이 그대로 저장함.
3. 로딩 실패(이미지 깨짐, 카드 자체 누락 등)로 보이는 항목은 발견되지 않음 — 모든 카드가 폰트명·제작사 정보를 온전히 갖고 있음(`name`/`maker` null 0건).
4. 스크롤 개수가 3,000개 이상으로 폭주하거나 광고/추천 위젯이 섞여 들어오는 등의 무한 루프 징후는 없었음 — 1,172개에서 정상적으로 로딩이 멈췄고, 추가 스크롤 시도에도 개수가 늘지 않아 카탈로그 전체가 로드됐다고 판단함.
5. **작업 경로 관련 참고**: 이 작업은 worktree 격리 에이전트로 실행돼, Playwright `browser_evaluate`의 파일 저장(filename 옵션)이 격리 정책과 무관하게 공유 체크아웃(`d:\MyCloud\Design_Blog\_workspace\`)에 접근 가능했다 — 최초 저장 시 실수로 그쪽에 파일이 생성돼 즉시 삭제하고, 이 worktree(`.claude\worktrees\agent-a6e964fd55d8fb9ba\_workspace\`) 경로로 다시 저장했다. 최종 산출물은 이 worktree 안에만 존재한다.
